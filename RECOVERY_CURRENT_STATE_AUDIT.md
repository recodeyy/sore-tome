### Root-cause conclusion

**The backend data and canonical wiring are correct.** The "blank pages / zero dashboards / empty lists" class of bugs is driven by **society scoping**, specifically:

- **FIND-001 (P1):** Phantom workspace. Account `admin-001` has Firestore `society_id="demo-soc-1"` that does not match its real Postgres membership (`hubtown-sunmist`). `addFirestoreDestinations` (`routes/auth.js:266`) adds a Firestore-derived admin workspace for `demo-soc-1` **in addition** to the real Postgres one → forces workspace selection and risks wrong-society scoping. Matches prompt §2 "phantom or incorrectly scoped workspaces."
- **FIND-002 (P1):** Unscoped-token zeros. With `society_id=null`, data endpoints **silently return empty/zero** instead of signaling "select a workspace." Any Flutter screen that loads before workspace selection shows zeros. Matches prompt §2 "auth failures caused by invalid/null society context."
